
# The Compass

The Compass is a career exploration platform designed to help first- and second-year university students navigate their academic and professional journeys.

## Problem

Many students feel uncertain about their future career paths and struggle to connect their current studies with long-term goals.

## Solution

The Compass provides:
- Career roadmaps
- Mentor insights
- Skill development guidance
- Industry-specific learning paths

## Target Users

- High school students
- First-year university students
- Second-year university students

## Features

- Interactive career roadmap
- Mentor Hub
- Industry exploration
- Actionable learning recommendations

## Technologies Used

- HTML
- CSS
- JavaScript

## Future Development

- Personalized career recommendations
- AI-powered mentor matching
- Progress tracking dashboard
